Logitech retains rights to these images and trademarks. No redistribution license is asserted. The UI concept in the project root remains the original generated reference.

Sidebar and action icons come from Lucide; the pinned source and ISC license are in `icons/`.

`vscode-stable.png` is the branded Visual Studio Code icon from [its official website](https://code.visualstudio.com/assets/apple-touch-icon.png), used to identify the application in this personal prototype. Microsoft retains its trademark rights. `vscode.png` is the unused Code OSS icon downloaded earlier from Microsoft's source repository.

Inter is from [Google Fonts](https://github.com/google/fonts/tree/main/ofl/inter). The bundled regular and semibold files are static instances of the upstream variable font (weight 400 / optical size 14 and weight 650 / optical size 32). See `fonts/Inter-OFL.txt`. Noto Sans Symbols 2 remains a fallback for status symbols.

## Signature M650 L

Two graphite, right-handed **large** product photos from [Logitech's official M650 L gallery (910-006231)](https://www.logitech.com/en-us/shop/p/m650-signature-wireless-mouse.910-006231), added 2026-10-09. These are browser-rendered PNG captures of the official images, rather than original transparent downloads. Logitech's image service pads the product to 1200 × 900 with the application's background color (`w_1200,h_900,c_pad,b_rgb:131616,f_png`); the app crops the surrounding browser margins using UV coordinates at rendering time. Each view loads on demand and works offline.
